# 결정 로그

## 제안
항목마다 표 한 줄: 항목 / 확실성 / 추천 / 이유 / 대안과 그 대안이 맞는 조건(판단만)
- 확정: 데이터나 규칙으로 답이 하나다. 근거 한 줄과 추천만 쓴다.
- 판단: 목적이나 업무 정의에 따라 달라진다. 추천, 이유, 대안, 결과 영향 방향을 쓴다.
- 미정: 요청자에게 물을 질문을 쓴다.
이유는 데이터(파일·값·개수)나 진술(INTERVIEW 번호)로 쓴다.

## 기록
work/DECISIONS.md 에 D-번호로 쓴다. 확정 항목은 하나의 번호로 묶어도 된다.
- 결정 / 근거 / 확인 방법(테스트 이름)
- 판단 항목은 대안과 영향을 추가한다.
결정이 바뀌면 이전 항목 제목에 `→ D-0xx 로 대체` 를 붙인다.
