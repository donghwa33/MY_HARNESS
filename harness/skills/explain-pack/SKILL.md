# 설명 팩

1. STATE·AGREEMENT·DECISIONS·FINDINGS·REVIEW 와 산출 문서를 읽는다.
2. 맨 위에 결론을 1~2문장으로 쓴다.
3. 예상 질문을 10개 안팎으로 만든다. 한 질문에는 한 주제만 담고, 다음을 포함한다:
   - 문제가 무엇이었나
   - 원인이 무엇이고 어떻게 확인했나
   - 다른 후보는 어떻게 다뤘나
   - 결과를 바꿀 수 있었던 데이터 처리 선택
   - 조치와 그 트레이드오프
   - 코드·도구가 깨질 수 있는 곳
   - 사람이 에이전트 결과를 바로잡은 일마다: 무엇이 틀렸고, 왜 그랬고, 어떻게 고쳤나 (DECISIONS 의 `(정정)`)
   - 질문자가 전제를 잘못 안 질문 1~2개
4. 질문마다 쓴다:
   - 답: 사람이 그대로 말할 1~2문장
   - 근거: 숫자 하나와 파일명
   - 약점: 내가 선택한 가정·기준·방법 중 틀릴 수 있는 것
   - 다음: 그것을 확인할 방법
   전제가 틀린 질문은 답 앞에 바로잡는 문장을 둔다. D·F·R 번호는 쓰지 않는다.
5. work/EXPLAIN_PACK.md 로 저장하고, 응답에 결론과 질문·답을 보여준다.
